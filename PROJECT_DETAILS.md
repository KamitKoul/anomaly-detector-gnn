# Deep Dive: Graph Neural Networks for Particle Anomaly Detection

## 🔬 Comprehensive Technical Overview & Implementation Details

### 🚀 1. Project Mission Elaborated
High Energy Physics (HEP) collider experiments generate massive amounts of data. The **Standard Model (SM)** describes "normal" expected background events perfectly, but physicists look for "New Physics" (Beyond the Standard Model, or BSM) which appear extremely rarely as anomalies.

- **The Problem:** Standard machine learning analyzes events as tabular lists, losing crucial relativistic geometric connections.
- **The Solution:** By transforming each collision into a **Relational Graph** and processing it through a specialized **Graph Attention Network (GAT)**, the AI learns the fundamental "grammar" of normal quantum interactions. Anything that reconstructs with high statistical error is mathematically flagged as a potential **Discovery Candidate**.

### 📐 2. Physical Graph Representation Detailed
The conversion of a flat particle list to a Graph object is done via the **Relativistic Physics Mapping** method in `src/run_lhco_gnn.py`.

#### A. Physics Extraction Pipeline
1. **Kinematic Tensor Construction:** For each collision, up to 700 variable particles are extracted from `data/`. Each consists of 3 coordinates:
   - $p_T$: Transverse Momentum (energy perpendicular to the beam).
   - $\eta$ (Eta): Pseudorapidity (the angle relative to the beam axis).
   - $\phi$ (Phi): The azimuthal angle around the detector ring.
2. **Logarithmic Momentum Compression:** Since $p_T$ spans orders of magnitude ($10^1$ to $10^5$), we apply $x' = \ln(1 + x)$. This prevents massive particles from dominating the numerical gradients while still maintaining their magnitude relationships.
3. **Global Coordinate Centering:** We calculate event-level means for $\eta$ and $\phi$ and subtract them to center the graph, making the learning rotationally and translationally equivariant.

#### B. $\Delta R$ Edge Connection Logic
The detector behaves cylindrically. To measure how "close" two particles are physically, we calculate the Relativistic Separation ($\Delta R$):
$$\Delta R = \sqrt{(\Delta\eta)^2 + (\Delta\phi)^2}$$
*Note: $\Delta\phi$ accounts for wrap-around periodicity at $2\pi$.*

- **Threshold Strategy ($\Delta R < 0.4$):** Particles generated by the hadronization of quarks and gluons form narrow cones called **"Jets"**. Setting this threshold explicitly links particles belonging to the same jet, giving the GNN immediate access to the local confinement structure of the strong nuclear force.

### 🧠 3. Deep Neural Architecture Elaborated
The Model, implemented in the `NodeGNN` class, is a sophisticated **Multi-Task Geometric Autoencoder**.

#### Phase 1: Graph Attention Encoder (Dynamic Routing)
Instead of averaging all neighboring particles equally, the model uses **Attention Heads** to learn which particle connections are physically relevant.
- **Input Dimension:** 3 Features per node $\to$ $[ \ln(1+p_T), \eta_{centered}, \phi_{centered} ]$.
- **Layer 1 (`GATConv`):** Maps the 3 features to 32 features using **4 distinct attention heads**. 
  - *Mechanics:* Each head performs independent attention weight calculation, resulting in $32 \times 4 = 128$ concatenated output features.
- **Layer 2 (`GATConv`):** Reads the 128 features and compresses them back down to a latent 32-dimensional tensor using a final single attention head.
- **Activation (`ELU`):** Used because Exponential Linear Units allow negative activations, enabling gradients to pass through smoothly even for highly disparate physics scales.

#### Phase 2: Multi-Task Decoder Heads
This is a crucial design choice. A standard autoencoder only reconstructs its inputs. Our system is forced to solve two physics problems simultaneously to learn richer latent embeddings:
1. **Reconstruction Decoder (Node Level):** Maps the latent 32 dimensions $\to$ 16 $\to$ original 3 dimensions. The goal is to precisely rebuild each particle's kinematic properties.
2. **Physics Head (Global Level):** Aggregates all learned node features via `global_mean_pool` into a single vector. It then regresses the missing transverse energy vector ($E_{x}^{miss}, E_{y}^{miss}$). 
   - *Why?* This guarantees that the GNN cannot just learn trivial geometry; it MUST understand vector energy conservation rules to satisfy the global loss.
