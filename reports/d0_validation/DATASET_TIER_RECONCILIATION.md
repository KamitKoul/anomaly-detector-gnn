## 3. Experiment Tier Definitions & Update Accounting

### Definitions:
- **Unique Events ($D$):** Number of distinct physical collision events present in the tier's `.npy` index file.
- **Batch Size ($B$):** Fixed at 32 across all experiments, with `drop_last = True`.
- **Updates per Epoch:** $\lfloor D / B \rfloor = \lfloor D / 32 \rfloor$.
- **Optimizer Updates ($U$):** Total parameter gradient steps.
- **Event Presentations ($P$):** Total event instances shown to the model ($U \times B$).
- **Mean Event Reuse Factor ($R$):** $P / D$.
